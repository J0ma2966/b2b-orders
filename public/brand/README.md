# Логотип OptoLink

Знак — два сцепленных кольца: поставщик и магазин в одной цепочке («O» и звено, link).

| Файл | Для чего |
|---|---|
| `logo.svg` | Знак + надпись, светлый фон |
| `logo-dark.svg` | Знак + надпись, тёмный фон |
| `logo-white.svg` | Белый, на фирменном фиолетовом или фото |
| `logo-mark.svg` | Только знак, цветной |
| `logo-mark-white.svg` | Только знак, белый |
| `app-icon.svg` | Иконка приложения (квадрат без скругления: скругляет система) |

Надпись переведена в кривые (шрифт Inter Display ExtraBold), шрифт для показа не нужен.

## Цвета

| | HEX |
|---|---|
| Фиолетовый (основной, «Link», правое кольцо) | `#5B3FD6` |
| Фиолетовый тёмный (низ градиента иконки) | `#4A2FC2` |
| Зелёный (левое кольцо) | `#16A34A` |
| Текст «Opto» | `#111827` |
| На тёмном фоне: кольца / «Link» | `#4ADE80`, `#A78BFA` / `#A78BFA` |
| На иконке: левое кольцо | `#86EFAC` |

## Правила

- Вокруг логотипа свободное поле не меньше толщины кольца.
- Знак без надписи меньше 16 px не ставить; надпись с знаком — от 24 px по высоте.
- Не менять цвета колец местами, не поворачивать, не добавлять тени и обводки.

## Иконки приложений

Растровые иконки собираются из `mobile/resources/*.png` командой `python3 scripts/mobile-icons.py`
(Android, iOS, PWA, заставки). Сайт: `src/app/icon.svg`, `src/app/favicon.ico`, `src/app/apple-icon.png`,
`public/icon-*.png` (в т.ч. `icon-maskable-512.png` для PWA).
